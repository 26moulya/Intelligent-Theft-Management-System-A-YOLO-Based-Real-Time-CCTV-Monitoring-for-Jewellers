Intelligent Theft Management System (ITMS)
A YOLO-Based Real-Time CCTV Monitoring System for Jewellers
Overview

The Intelligent Theft Management System (ITMS) is an AI-powered real-time surveillance solution developed to improve security in jewelry stores and other high-risk retail environments. The system uses the YOLOv5 deep learning object detection model to monitor CCTV video streams and detect suspicious activities, unauthorized intrusions, and potential theft attempts automatically.

The project aims to reduce dependency on manual monitoring by providing automated detection, instant alerts, and continuous surveillance with high accuracy and low latency.

Features
Real-time CCTV video monitoring
YOLOv5-based human/object detection
Detection under daylight, low-light, and nighttime conditions
Automated SMS and email alert system
Adjustable confidence threshold settings
Browser-based admin dashboard
Frame-by-frame video analysis
High-speed and low-latency processing
Scalable and efficient surveillance solution
